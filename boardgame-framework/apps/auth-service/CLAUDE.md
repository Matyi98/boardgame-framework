# CLAUDE.md — apps/auth-service

## What this service does
JWT-based authentication. Register, login, and verify user identity.  
The only service that reads/writes the `users` Postgres table.  
All other services validate JWTs locally — no round-trips to auth-service at runtime.

## Key files
| File | Role |
|------|------|
| `src/auth/auth.controller.ts` | `POST /api/auth/register`, `POST /api/auth/login`, `GET /api/auth/me` |
| `src/auth/auth.service.ts` | Bcrypt hashing, JWT minting with `@nestjs/jwt` |
| `src/users/user.entity.ts` | TypeORM entity: `id UUID PK, username TEXT UNIQUE, passwordHash TEXT` |
| `src/users/users.service.ts` | `findByUsername(name)`, `create(name, hash)` |

## JWT payload
```ts
{ sub: userId, username: string }
```
`sub` is a UUID auto-generated by Postgres on `INSERT`.  
`userId` in all other services = this `sub` value.

## API
```
POST /api/auth/register  { username, password }  → AuthResponse
POST /api/auth/login     { username, password }  → AuthResponse
GET  /api/auth/me        (Bearer token required) → { userId, username }
```

```ts
interface AuthResponse {
  userId: string;      // UUID
  username: string;
  accessToken: string; // JWT, default 7d TTL
}
```

## JWT validation in other services
Other services (lobby, realtime-gateway) receive the JWT and verify it themselves:
```ts
const payload = this.jwt.verify<{ sub: string; username: string }>(token, { secret: JWT_SECRET });
// payload.sub === userId
```
No network call needed — just the shared `JWT_SECRET` env var.

## Postgres table
```sql
CREATE TABLE users (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  username     TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,
  created_at   TIMESTAMPTZ DEFAULT now()
);
```
