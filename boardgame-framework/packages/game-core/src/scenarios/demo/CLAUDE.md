# CLAUDE.md — Frontier Scenario (demo-v1)

## Overview
Frontier is the only implemented game scenario. All its code is in this directory.

## Files
| File | Purpose |
|------|---------|
| `scenario.ts` | The `demoScenario` object — wires everything together |
| `map.ts` | `buildDemoMap()` — 19 axial hex tiles in 2 rings |
| `actions.ts` | `claim-tile` and `end-turn` validators + executors |
| `victory.ts` | `firstToTwelveVP` and `allTilesClaimed` win conditions |
| `index.ts` | Re-exports |

## Game rules
- 2–4 players, each starts with a pre-claimed home tile on ring 2
- On your turn: click an adjacent unclaimed tile → claimed + turn ends automatically
- No tile to claim? Click "pass →" to end turn manually
- **Dice**: a d6 is rolled on every claim (via `state.rng`); roll 6 = +1 bonus VP
- Win: first to **12 VP**, or highest VP when all 19 tiles are claimed

## Tile coordinates (axial q,r)
```
Ring 0 (center): (0,0)
Ring 1: (1,0),(1,-1),(0,-1),(-1,0),(-1,1),(0,1)
Ring 2: (2,0),(2,-1),(2,-2),(1,-2),(0,-2),(-1,-1),(-2,0),(-2,1),(-2,2),(-1,2),(0,2),(1,1)
```
Tile IDs are the string `"q,r"`, generated by `tileId({ q, r })` from `../../map/tile.js`.

## Starting positions by player count
```
2P: (2,-1) and (-2,1)
3P: (2,0), (-1,-1), (-1,2)
4P: (2,0), (-2,0), (0,-2), (0,2)
```
